# Smart Support Ticket Intelligence System

> AI/ML Internship Assessment Project — TARS Technologies

An end-to-end Natural Language Processing and Machine Learning system that automatically predicts the **category** and **priority** of customer support tickets from their text.

---

## 📌 Project Overview

Customer support teams receive a large number of tickets every day. Manually reading, categorizing, and prioritizing these tickets can be time-consuming.

This project uses **NLP + Machine Learning** to automate the initial ticket triage process.

Given a new support ticket, the system predicts:

- 🎯 Ticket Category
- 🚨 Ticket Priority

### Example

**Input**

```text
My payment was deducted but my order was cancelled.
````

**Prediction**

```text
Category : Billing and Payments
Priority : High
```

The prediction is generated by the trained machine learning models.

---

# 🎯 Problem Statement

Build a machine learning system that takes customer support ticket text as input and predicts:

1. The appropriate support ticket category
2. The appropriate ticket priority

# 🔄 Feature Mapping

The original dataset fields are mapped to the machine learning problem as follows:

```text
subject + body
       │
       ▼
 ticket_text
```

Target variables:

```text
queue      → category
priority   → priority
```

Therefore:

```text
INPUT

ticket_text


OUTPUT

category
priority
```

---

# 🔐 Data Leakage Prevention

The model must only use information that would be available when a new ticket arrives.

The following fields are therefore excluded from the model input:

```text
queue
priority
answer
```

The model receives only:

```text
subject + body
```

This prevents target leakage and ensures that the prediction process represents a realistic support-ticket workflow.

# 🔢 TF-IDF

TF-IDF stands for:

**Term Frequency — Inverse Document Frequency**

It assigns higher importance to words that are useful for distinguishing documents while reducing the importance of words that occur frequently across many documents.

The project uses:

```python
from sklearn.feature_extraction.text import TfidfVectorizer

vectorizer = TfidfVectorizer(
    lowercase=True,
    stop_words="english",
    ngram_range=(1, 2),
    min_df=2,
    sublinear_tf=True
)
```

---

# 📌 Why TF-IDF?

TF-IDF was selected because:

* It is effective for text classification
* It works well with sparse text data
* It is computationally efficient
* It is easy to understand
* It works well with linear classifiers
* It is appropriate for the scale and requirements of this assessment

# 📏 Model Evaluation

The following metrics are calculated:

## Accuracy

Percentage of predictions that are correct.

## Precision

Measures how many predicted samples belonging to a class are actually correct.

## Recall

Measures how many actual samples belonging to a class are correctly identified.

## F1-score

Harmonic mean of precision and recall.

## Macro F1-score

Calculates F1 independently for each class and then gives equal importance to every class.

This is useful when class distributions are imbalanced.

# ⚠️ Limitations

The current system has some limitations:

1. TF-IDF does not understand complete semantic context.
2. Synonyms may not always be treated as equivalent.
3. Rare classes may contain fewer training examples.
4. Performance depends on dataset quality.
5. New ticket formats may reduce prediction performance.
6. The system is designed for the internship assessment and is not yet a production-grade support platform.
